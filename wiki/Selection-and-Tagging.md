# Selection & Tagging

## Selecting designs
- Tick the **checkbox** in the corner of a design card (or in the first column of Table View) to add it to your selection. Tick more boxes to select several designs.
- `Ctrl`-click adds or removes one design. `Shift`-click selects a range of designs.
- A normal click selects just that one design.
- Press `Esc` to go back to a single selection.
- The **Tag Selected (N)** button shows how many designs are selected.

## Tagging
- **Tag Selected (N)** opens the bulk tag window: type tags separated by commas, or click a quick tag like `favorite` or `gift`.
- In the right-hand inspector you can add a single tag (press `F2` to jump to the quick tag box), remove a tag with ✕, and write notes.
- Tags and notes are searchable and appear in the **Craft Tag** filter.

## Opening a design in your embroidery software
Double-click a design card or table row, or click **Open in Default App**, to open it in the program Windows uses for that file type (for example Wilcom Hatch or Brother PE-Design). If no program is set for that file type, Stitchidex shows a message instead.
