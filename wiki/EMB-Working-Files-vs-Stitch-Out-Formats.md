# .EMB Working Files vs Stitch-Out Formats

## Two kinds of embroidery files
- **Working / source designs (.EMB)**: Wilcom Hatch and Wilcom EmbroideryStudio save your editable design as `.emb`. It keeps objects, lettering and settings so you can keep editing. Machines cannot sew an `.emb` file directly.
- **Stitch-out files**: the machine-ready files you export from Hatch and put on a USB stick: `.vp3`, `.pes`, `.dst`, `.jef`, `.exp`, `.xxx`, `.hus`, `.pec` and more.

## How Stitchidex shows .EMB files
`.emb` files are labeled **Source (.EMB)** with the format "Wilcom / Hatch Source Design". Stitchidex does not decode Wilcom's private stitch data, so size and stitch count are not shown for `.emb` files. Double-click the design (or click **Open in Default App**) to open it in Hatch.

## Hide working files with one click
Tick **Stitch-Out Files Only (Hide .EMB)** in the sidebar to hide every `.emb` file and only see files you can send to your machine. Untick it to see everything again.
